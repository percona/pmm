# Delete a backup

You can only delete backup artifacts stored on Amazon S3-compatible. Local backups must be removed manually.

To delete a backup:
{.power-number}

1. Go to  :material-history: **Backup > All backups** and find the row with the backup you want to delete.
2. Click the arrow in the **Actions** column to check all the information for the backup, then click :material-dots-vertical: **> Delete backup**.
3. In the **Delete backup artifact** dialog box, enable **Delete from storage** if you also want to delete the actual backup content besides just the backup register.
4. Click **Delete**.
